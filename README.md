# PLAY pay — музыкальный плеер для Android

Kotlin + Jetpack Compose + Media3 (ExoPlayer).

## Музыка (главное)
- 🔎 **Сканирование устройства** — память телефона и SD-карта (через системную медиатеку)
- 📁 **Добавить папку** — любую, в том числе на карте памяти (если сканер её не увидел)
- 🎵 **Добавить файлы** вручную
- Вкладки: Треки · Альбомы · Исполнители · Папки · Избранное, поиск, сортировка
- Обложки из файлов, очередь («играть следующим», «в очередь»), перемешивание, повтор, скорость 0.75–2×
- Продолжение с того же места после перезапуска
- «Открыть с помощью PLAY pay» для аудиофайлов из других приложений

## Радио (дополнительно)
- Каталог Radio Browser, 14 стран на выбор + поиск по миру
- **Выбор битрейта**: в настройках (Авто / Экономия 64 / Стандарт 128 / Максимум) и прямо в плеере, если у станции несколько потоков
- Экономия трафика в мобильной сети, автопереключение недоступной станции

## Настройки
Цвет (10 схем + свой оттенок), тема (тёмная / чёрная AMOLED / светлая), эквалайзер с пресетами,
пропуск тишины, пауза при отключении наушников, фильтр коротких файлов и мессенджеров,
стартовый раздел, анимации, «не гасить экран».

## Развлечения
- 🏃 **Кот-бегун** — вислоухий кот бежит по ночному городу и прыгает на сильную долю, дома пульсируют под бас
- Танцующие персонажи и 12 звуковых эффектов
- 🎮 Игры: **Змейка** и **Лови ноты** (под музыку ноты падают быстрее)

## Как собрать APK через GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него **содержимое** этой папки (чтобы `settings.gradle.kts` и папка `.github` были в корне).
3. Вкладка **Actions** → workflow «Build APK» запустится сам (или «Run workflow»).
4. Через ~5–8 минут: запуск → **Artifacts** → скачайте `PLAY-pay-apk`.
5. Установите APK. Если на телефоне стоит старый VibeRadio и установка не проходит — удалите его сначала
   (у каждой сборки GitHub свой отладочный ключ подписи).

Минимальная версия Android — 7.0.
